# 🍕 Pizza Delivery Performance Analysis (Power BI Project)

An interactive Power BI dashboard analyzing pizza orders and delivery performance across multiple U.S. cities. This project identifies operational bottlenecks, customer preferences, and delay trends to drive smarter business decisions.

---

## 🚀 Project Objectives

- Analyze order volume, delivery delays, and performance by city, restaurant, and pizza type.
- Identify causes of delivery delays and customer behavior trends.
- Deliver interactive, filterable dashboards using Power BI.
- Provide actionable insights for improving delivery speed and customer satisfaction.

---

## 🧰 Tools & Technologies Used

- **Power BI Desktop**
- **Power Query (M language)**
- **DAX (Data Analysis Expressions)**
- **Microsoft Excel**

---

## 🧱 Project Architecture
- Excel/CSV → Power Query (Clean & Transform)
- Star Schema Data Model
- DAX Measures (KPIs)
- Power BI Visuals & Dashboards


---

## 📊 Dashboard Features

- 📍 City-wise and restaurant-wise performance tracking  
- ⏱️ Delay analysis by traffic, peak hour, and pizza type  
- 💳 Payment trends and pizza size preferences  
- 📅 Time-based slicers, drill-throughs, and interactive tooltips  
- 🧠 Dynamic KPIs: Avg Delivery Time, Delay %, On-Time Rate
